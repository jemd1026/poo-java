Patrón de diseño MVC

MVC organiza una aplicación en Modelo, Vista y Controlador. Cada parte tiene una responsabilidad clara y colabora con las demás para responder a las acciones del usuario.

Idea clave: la Vista presenta y captura información; el Controlador coordina la acción; el Modelo contiene los datos y las reglas del negocio.

1. ¿Qué es MVC?

MVC significa Modelo–Vista–Controlador. Es un patrón arquitectónico que separa responsabilidades para que la interfaz, la lógica del sistema y la coordinación no queden mezcladas en una sola clase.

VistaMuestra datos y registra acciones
→
ControladorRecibe la acción y coordina
→
ModeloAplica reglas y administra datos
Importante: MVC no es una clase especial de Java ni una biblioteca obligatoria. Es una forma de organizar las clases de una aplicación.

2. Los tres componentes

Modelo

Representa los datos y las reglas del negocio. Calcula, valida o modifica información. No debe depender de cómo se dibuja la interfaz.

Vista

Es la interfaz con la que interactúa el usuario. Presenta información y captura acciones, sin implementar las reglas del negocio.

Controlador

Interpreta las acciones recibidas, solicita al Modelo el trabajo necesario y decide qué resultado mostrar en la Vista.

Regla para reconocerlos: pregunta si la clase representa datos y reglas (Modelo), muestra o recibe información (Vista) o coordina la interacción (Controlador).

3. ¿Cómo funciona el flujo?

En este ejemplo, la persona solicita ver el precio de un producto con descuento. El Controlador coordina el proceso, pero el cálculo pertenece al Modelo.

AcciónLa persona solicita aplicar un descuento desde la Vista.
CoordinaciónEl Controlador recibe la solicitud y consulta al Modelo.
Regla del negocioEl Modelo calcula el precio final.
RespuestaEl Controlador entrega el resultado a la Vista para presentarlo.
En resumen: Vista → Controlador → Modelo → Controlador → Vista.

Archivo 1 · Producto.java (dentro del paquete tienda.modelo)

package tienda.modelo;

public class Producto {
    private final String nombre;
    private final double precio;

    public Producto(String nombre, double precio) {
        this.nombre = nombre;
        this.precio = precio;
    }

    public String getNombre() {
        return nombre;
    }

    public double calcularPrecioConDescuento(double porcentaje) {
        return precio - (precio * porcentaje / 100);
    }
}

Archivo 2 · ProductoView.java (dentro del paquete tienda.vista)

package tienda.vista;

public class ProductoView {
    public void mostrarPrecioFinal(String nombre, double precioFinal) {
        System.out.println("Precio final de " + nombre + ": " + precioFinal);
    }
}

Archivo 3 · ProductoController.java (dentro del paquete tienda.controlador)

package tienda.controlador;

import tienda.modelo.Producto;
import tienda.vista.ProductoView;

public class ProductoController {
    private final Producto modelo;
    private final ProductoView vista;

    public ProductoController(Producto modelo, ProductoView vista) {
        this.modelo = modelo;
        this.vista = vista;
    }

    public void mostrarPrecioConDescuento(double porcentaje) {
        double precioFinal = modelo.calcularPrecioConDescuento(porcentaje);
        vista.mostrarPrecioFinal(modelo.getNombre(), precioFinal);
    }
}

Archivo 4 · Main.java (dentro del paquete tienda)

package tienda;

import tienda.controlador.ProductoController;
import tienda.modelo.Producto;
import tienda.vista.ProductoView;

public class Main {
    public static void main(String[] args) {
        Producto modelo = new Producto("Cuaderno", 100.0);
        ProductoView vista = new ProductoView();
        ProductoController controlador = new ProductoController(modelo, vista);

        controlador.mostrarPrecioConDescuento(10);
    }
}

5. Beneficios y buenas prácticas

Más orden

Cada clase tiene un propósito reconocible, así es más sencillo comprender el programa.

Mantenimiento sencillo

Se puede modificar la presentación sin reescribir el cálculo del Modelo.

Trabajo en equipo

Distintas personas pueden trabajar en la interfaz, las reglas y la coordinación.

  • Mantén las reglas de negocio en el Modelo, no en los botones o formularios.
  • Evita que la Vista realice directamente los cálculos del Modelo.
  • Deja que el Controlador coordine; no conviertas una clase en responsable de todo.
  • Usa nombres que indiquen claramente si una clase es modelo, vista o controlador.
Nota: las interacciones exactas entre los componentes pueden variar según la aplicación o el framework. Lo esencial es mantener separadas sus responsabilidades.

6. Práctica: formulario Registro de Personas con MVC

Esta práctica aplica MVC en una ventana Swing. El formulario registra personas, calcula su edad a partir de la fecha de nacimiento y las muestra en una tabla, con las opciones Agregar, Modificar, Eliminar y Limpiar.

VistaEl usuario completa los datos y pulsa Agregar.
ControladorLee los datos de la Vista y crea un objeto Persona.
ModeloVerifica que el DNI no se repita, guarda la persona y calcula la edad.
VistaEl Controlador le pide actualizar la tabla y mostrar la edad.

6.2 Modelo: clase Persona

Dentro de registro.modelo, crea la clase Persona con New → Java Class. Representa los datos de una persona y contiene la regla para calcular la edad.

Archivo · Persona.java (dentro del paquete registro.modelo)

package registro.modelo;

import java.time.LocalDate;
import java.time.Period;

public class Persona {
    private final String dni;
    private final String nombres;
    private final String telefono;
    private final String direccion;
    private final String email;
    private final String sexo;
    private final String profesion;
    private final LocalDate fechaNacimiento;

    public Persona(String dni, String nombres, String telefono, String direccion,
                   String email, String sexo, String profesion, LocalDate fechaNacimiento) {
        this.dni = dni;
        this.nombres = nombres;
        this.telefono = telefono;
        this.direccion = direccion;
        this.email = email;
        this.sexo = sexo;
        this.profesion = profesion;
        this.fechaNacimiento = fechaNacimiento;
    }

    public int calcularEdad() {
        return Period.between(fechaNacimiento, LocalDate.now()).getYears();
    }

    public String getDni() {
        return dni;
    }

    public String getNombres() {
        return nombres;
    }

    public String getTelefono() {
        return telefono;
    }

    public String getDireccion() {
        return direccion;
    }

    public String getEmail() {
        return email;
    }

    public String getSexo() {
        return sexo;
    }

    public String getProfesion() {
        return profesion;
    }

    public LocalDate getFechaNacimiento() {
        return fechaNacimiento;
    }
}

6.3 Modelo: clase RegistroPersonas

En el mismo paquete, crea RegistroPersonas. Guarda la lista de personas en memoria y aplica la regla del negocio: no puede haber dos personas con el mismo DNI.

Archivo · RegistroPersonas.java (dentro del paquete registro.modelo)

package registro.modelo;

import java.util.ArrayList;
import java.util.List;

public class RegistroPersonas {
    private final List<Persona> personas = new ArrayList<>();

    public boolean agregar(Persona persona) {
        if (buscarIndice(persona.getDni()) != -1) {
            return false;
        }
        personas.add(persona);
        return true;
    }

    public boolean modificar(Persona persona) {
        int indice = buscarIndice(persona.getDni());
        if (indice == -1) {
            return false;
        }
        personas.set(indice, persona);
        return true;
    }

    public void eliminar(int indice) {
        personas.remove(indice);
    }

    public List<Persona> listar() {
        return personas;
    }

    private int buscarIndice(String dni) {
        for (int i = 0; i < personas.size(); i++) {
            if (personas.get(i).getDni().equals(dni)) {
                return i;
            }
        }
        return -1;
    }
}

Observa que el Modelo no usa JOptionPane ni componentes Swing: solo devuelve true o false. Decidir qué mensaje mostrar le corresponde al Controlador y a la Vista.

6.6 Programar los métodos de la Vista

Cambia a la vista Source de FrmPersona.java. La Vista solo lee lo que escribió el usuario, muestra datos y presenta mensajes; no decide ni calcula nada.

  1. Debajo de la línea package registro.vista;, agrega los import.
  2. Después de public class FrmPersona extends javax.swing.JFrame {, agrega la constante FORMATO y el atributo modeloTabla.
  3. Completa el constructor FrmPersona() después de initComponents();.
  4. Escribe los demás métodos debajo del constructor y antes de initComponents() (la zona gris generada por NetBeans no se puede editar).

Archivo · FrmPersona.java (código que agregas en Source)

package registro.vista;

import java.awt.event.ActionListener;
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.time.format.ResolverStyle;
import java.util.List;
import javax.swing.JOptionPane;
import javax.swing.event.ListSelectionListener;
import javax.swing.table.DefaultTableModel;
import registro.modelo.Persona;

public class FrmPersona extends javax.swing.JFrame {

    private static final DateTimeFormatter FORMATO = DateTimeFormatter.ofPattern("dd/MM/uuuu")
            .withResolverStyle(ResolverStyle.STRICT);
    private final DefaultTableModel modeloTabla;

    public FrmPersona() {
        initComponents();
        modeloTabla = new DefaultTableModel(new Object[]{"DNI", "Nombres", "Teléfono",
            "Dirección", "Email", "Sexo", "Profesión", "F. Nacimiento", "Edad"}, 0);
        tblPersonas.setModel(modeloTabla);
        tblPersonas.setDefaultEditor(Object.class, null);
        setLocationRelativeTo(null);
    }

    public void agregarEventos(ActionListener accion, ListSelectionListener seleccion) {
        btnAgregar.addActionListener(accion);
        btnModificar.addActionListener(accion);
        btnEliminar.addActionListener(accion);
        btnLimpiar.addActionListener(accion);
        tblPersonas.getSelectionModel().addListSelectionListener(seleccion);
    }

    public String getDni() {
        return txtDni.getText().trim();
    }

    public String getNombres() {
        return txtNombres.getText().trim();
    }

    public String getTelefono() {
        return txtTelefono.getText().trim();
    }

    public String getDireccion() {
        return txtDireccion.getText().trim();
    }

    public String getEmail() {
        return txtEmail.getText().trim();
    }

    public String getSexo() {
        if (rbMasculino.isSelected()) {
            return "Masculino";
        }
        if (rbFemenino.isSelected()) {
            return "Femenino";
        }
        return "";
    }

    public String getProfesion() {
        if (cboProfesion.getSelectedIndex() == 0) {
            return "";
        }
        return cboProfesion.getSelectedItem().toString();
    }

    public LocalDate getFechaNacimiento() {
        return LocalDate.parse(txtFechaNac.getText().trim(), FORMATO);
    }

    public int getFilaSeleccionada() {
        return tblPersonas.getSelectedRow();
    }

    public void listar(List<Persona> personas) {
        modeloTabla.setRowCount(0);
        for (Persona p : personas) {
            modeloTabla.addRow(new Object[]{p.getDni(), p.getNombres(), p.getTelefono(),
                p.getDireccion(), p.getEmail(), p.getSexo(), p.getProfesion(),
                p.getFechaNacimiento().format(FORMATO), p.calcularEdad()});
        }
    }

    public void mostrarPersona(Persona p) {
        txtDni.setText(p.getDni());
        txtNombres.setText(p.getNombres());
        txtTelefono.setText(p.getTelefono());
        txtDireccion.setText(p.getDireccion());
        txtEmail.setText(p.getEmail());
        if (p.getSexo().equals("Masculino")) {
            rbMasculino.setSelected(true);
        } else {
            rbFemenino.setSelected(true);
        }
        cboProfesion.setSelectedItem(p.getProfesion());
        txtFechaNac.setText(p.getFechaNacimiento().format(FORMATO));
        mostrarEdad(p.calcularEdad());
    }

    public void mostrarEdad(int edad) {
        txtEdad.setText(String.valueOf(edad));
    }

    public void limpiar() {
        txtDni.setText("");
        txtNombres.setText("");
        txtTelefono.setText("");
        txtDireccion.setText("");
        txtEmail.setText("");
        grupoSexo.clearSelection();
        cboProfesion.setSelectedIndex(0);
        txtFechaNac.setText("");
        txtEdad.setText("");
        tblPersonas.clearSelection();
        txtDni.requestFocus();
    }

    public void mostrarMensaje(String mensaje) {
        JOptionPane.showMessageDialog(this, mensaje);
    }

    public boolean confirmar(String mensaje) {
        return JOptionPane.showConfirmDialog(this, mensaje, "Confirmar",
                JOptionPane.YES_NO_OPTION) == JOptionPane.YES_OPTION;
    }

    // Debajo queda el código generado por NetBeans: initComponents() y las variables.
}
Formato estricto: con ResolverStyle.STRICT, una fecha inexistente como 31/02/2000 se rechaza en lugar de corregirse en silencio a 29/02/2000. En modo estricto el año se escribe uuuu; con yyyy ninguna fecha sería válida.
Dos nombres parecidos: modeloTabla es el modelo de datos del JTable (una clase de Swing), no el Modelo de MVC. Además, borra el método main que NetBeans generó en FrmPersona: si ejecutas el formulario por sí solo no tendrá Controlador y los botones no harán nada.

6.7 Controlador: clase PersonaController

En registro.controlador, crea PersonaController. Implementa dos interfaces de Swing: ActionListener, para los botones, y ListSelectionListener, para detectar la fila elegida en la tabla.

Archivo · PersonaController.java (dentro del paquete registro.controlador)

package registro.controlador;

import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;
import java.time.LocalDate;
import java.time.Period;
import java.time.format.DateTimeParseException;
import javax.swing.event.ListSelectionEvent;
import javax.swing.event.ListSelectionListener;
import registro.modelo.Persona;
import registro.modelo.RegistroPersonas;
import registro.vista.FrmPersona;

public class PersonaController implements ActionListener, ListSelectionListener {
    private final RegistroPersonas modelo;
    private final FrmPersona vista;

    public PersonaController(RegistroPersonas modelo, FrmPersona vista) {
        this.modelo = modelo;
        this.vista = vista;
        vista.agregarEventos(this, this);
    }

    @Override
    public void actionPerformed(ActionEvent e) {
        String accion = e.getActionCommand();
        if (accion.equals("Agregar")) {
            agregar();
        } else if (accion.equals("Modificar")) {
            modificar();
        } else if (accion.equals("Eliminar")) {
            eliminar();
        } else if (accion.equals("Limpiar")) {
            vista.limpiar();
        }
    }

    @Override
    public void valueChanged(ListSelectionEvent e) {
        int fila = vista.getFilaSeleccionada();
        if (e.getValueIsAdjusting() || fila == -1) {
            return;
        }
        vista.mostrarPersona(modelo.listar().get(fila));
    }

    private void agregar() {
        Persona persona = leerPersona();
        if (persona == null) {
            return;
        }
        if (modelo.agregar(persona)) {
            vista.listar(modelo.listar());
            vista.mostrarEdad(persona.calcularEdad());
            vista.mostrarMensaje("Persona agregada.");
        } else {
            vista.mostrarMensaje("Ya existe una persona con el DNI " + persona.getDni() + ".");
        }
    }

    private void modificar() {
        Persona persona = leerPersona();
        if (persona == null) {
            return;
        }
        if (modelo.modificar(persona)) {
            vista.listar(modelo.listar());
            vista.mostrarEdad(persona.calcularEdad());
            vista.mostrarMensaje("Persona modificada.");
        } else {
            vista.mostrarMensaje("No existe una persona con el DNI " + persona.getDni() + ".");
        }
    }

    private void eliminar() {
        int fila = vista.getFilaSeleccionada();
        if (fila == -1) {
            vista.mostrarMensaje("Selecciona una persona en la tabla.");
            return;
        }
        Persona persona = modelo.listar().get(fila);
        if (vista.confirmar("¿Eliminar a " + persona.getNombres() + "?")) {
            modelo.eliminar(fila);
            vista.listar(modelo.listar());
            vista.limpiar();
        }
    }

    private Persona leerPersona() {
        String error = validar();
        if (error != null) {
            vista.mostrarMensaje(error);
            return null;
        }
        return new Persona(vista.getDni(), vista.getNombres(), vista.getTelefono(),
                vista.getDireccion(), vista.getEmail(), vista.getSexo(),
                vista.getProfesion(), vista.getFechaNacimiento());
    }

    private String validar() {
        if (vista.getDni().isEmpty() || vista.getNombres().isEmpty()
                || vista.getSexo().isEmpty() || vista.getProfesion().isEmpty()) {
            return "Completa DNI, nombres, sexo y profesión.";
        }
        if (!vista.getDni().matches("\\d{8}")) {
            return "El DNI debe tener exactamente 8 dígitos.";
        }
        if (!vista.getNombres().matches("[\\p{L} ]+")) {
            return "Los nombres solo pueden contener letras y espacios.";
        }
        if (!vista.getTelefono().isEmpty() && !vista.getTelefono().matches("\\d{9}")) {
            return "El teléfono debe tener 9 dígitos.";
        }
        if (!vista.getEmail().isEmpty()
                && !vista.getEmail().matches("[\\w.+-]+@[\\w-]+(\\.[\\w-]+)+")) {
            return "Escribe un email válido, por ejemplo juan@example.com.";
        }

        LocalDate fecha;
        try {
            fecha = vista.getFechaNacimiento();
        } catch (DateTimeParseException ex) {
            return "Escribe una fecha válida con el formato dd/MM/aaaa.";
        }
        if (fecha.isAfter(LocalDate.now())) {
            return "La fecha de nacimiento no puede ser futura.";
        }
        if (Period.between(fecha, LocalDate.now()).getYears() > 120) {
            return "Revisa la fecha de nacimiento: la edad supera los 120 años.";
        }
        return null;
    }
}

El Controlador nunca toca un JTextField ni la lista de personas directamente: pide los datos a la Vista mediante sus métodos y delega las reglas al Modelo.

El método validar() revisa los datos en orden y devuelve el primer error que encuentra, o null si todo está correcto. Así, leerPersona() solo crea el objeto Persona cuando los datos son válidos. Las reglas que usan matches(...) comparan el texto con una expresión regular:

ExpresiónSignificadoVálidoNo válido
\\d{8}Exactamente 8 dígitos123456781234, 1234567A
[\\p{L} ]+Letras (incluye tildes y ñ) y espaciosMaría PeñaJuan123
\\d{9}Exactamente 9 dígitos98765432198765
[\\w.+-]+@[\\w-]+(\\.[\\w-]+)+Texto, @, dominio y al menos un puntojuan@example.comjuan@, juan.com
Campos opcionales: teléfono y email solo se validan si el usuario escribió algo; si quedan vacíos, se aceptan. En Java, la barra invertida se escribe doble dentro de un String: "\\d" representa la expresión \d (un dígito).

Opción B: título con ícono (por código)

En Design, un Titled Border no admite íconos. Para mostrar un ícono sobre la línea del borde, crea el borde por código: su título acepta HTML y puede incluir una imagen guardada en src/main/resources. Agrega este método en FrmPersona, debajo del constructor:

private javax.swing.border.Border crearBorde(String titulo, String imagen) {
    java.net.URL url = getClass().getResource(imagen);
    return javax.swing.BorderFactory.createTitledBorder(
            javax.swing.BorderFactory.createLineBorder(new java.awt.Color(200, 215, 235), 1, true),
            "<html><img src='" + url + "' width='20' height='20'>&nbsp;" + titulo + "</html>",
            javax.swing.border.TitledBorder.LEFT, javax.swing.border.TitledBorder.TOP,
            new java.awt.Font("Segoe UI", java.awt.Font.BOLD, 14), new java.awt.Color(13, 71, 161));
}

Luego, en el constructor, después de initComponents();:

pnlDatos.setBorder(crearBorde("Datos de la Persona", "/14_personas.png"));
pnlLista.setBorder(crearBorde("Lista de Personas", "/14_personas.png"));
Nota: width='20' height='20' reduce la imagen al dibujarla, aunque el archivo sea más grande. El borde con ícono no se ve en Design; aparece al ejecutar Main.java.

Para seguir practicando

  • Modelo: mueve el método validar() a RegistroPersonas, de modo que reciba un objeto Persona y devuelva el mensaje de error. ¿Qué ventaja tendría si mañana la Vista fuera una página web?
  • Vista y Controlador: agrega un campo y un botón Buscar que encuentre una persona por DNI.
  • Vista: reemplaza txtFechaNac por un selector de fecha (por ejemplo, JDateChooser de la biblioteca JCalendar). Comprueba que el Modelo y el Controlador casi no cambian.
