Herencia y polimorfismo en Java

Trabaja con los paquetes herencia y polimorfismo para reutilizar código, especializar comportamientos y aplicar sobrecarga y sobrescritura.

2. Herencia

La herencia permite crear una clase hija a partir de una clase padre. La subclase reutiliza los atributos y métodos heredables de la superclase y agrega características propias.

Superclase

Clase padre de la cual se hereda una estructura común.

Subclase

Clase hija que recibe y especializa miembros de la superclase.

extends

Palabra reservada que declara la relación de herencia.

2.1 Clase padre: Persona.java

package herencia;

        public class Persona {
        protected int id;
        protected String dni;
        protected String nombre;
        protected String apellido;

        public Persona(int id, String dni, String nombre, String apellido) {
        this.id = id;
        this.dni = dni;
        this.nombre = nombre;
        this.apellido = apellido;
        }

        public void mostrarDatos() {
        System.out.println("ID: " + id);
        System.out.println("DNI: " + dni);
        System.out.println("Nombre: " + nombre);
        System.out.println("Apellido: " + apellido);
        }

        public void actividad() {
        System.out.println("La persona realiza una actividad");
        }
        }

Los atributos son protected para que puedan utilizarse dentro de las subclases.

2.2 Clase hija: Empleado.java

package herencia;

        public class Empleado extends Persona {
        private double sueldo;

        public Empleado(int id, String dni, String nombre,
        String apellido, double sueldo) {
        super(id, dni, nombre, apellido);
        this.sueldo = sueldo;
        }

        public double getSueldo() {
        return sueldo;
        }
        }

3. Uso de super

super hace referencia a la clase padre. Permite llamar al constructor del padre o a la versión de un método definida allí.

3.1 Constructor del padre

super(id, dni, nombre, apellido);

Esta instrucción ejecuta el constructor de Persona. Debe ser la primera instrucción del constructor de la clase hija.

3.2 Método del padre

super.mostrarDatos();

Esta llamada ejecuta específicamente la versión de mostrarDatos() declarada en Persona.

4. Sobrescritura con @Override

La sobrescritura permite que una clase hija proporcione su propia implementación de un método heredado.

4.1 Clase Consultor.java

package herencia;

        public class Consultor extends Persona {
        private String nombreConsultora;

        public Consultor(int id, String dni, String nombre,
        String apellido, String nombreConsultora) {
        super(id, dni, nombre, apellido);
        this.nombreConsultora = nombreConsultora;
        }

        @Override
        public void actividad() {
        System.out.println("El consultor brinda asesoría");
        }
        }

Agrega dentro de Empleado.java:

@Override
        public void actividad() {
        System.out.println("El empleado trabaja en la empresa");
        }

4.2 Ejecutar la sobrescritura

package herencia;

        public class PruebaHerencia {
        public static void main(String[] args) {
        Persona persona = new Persona(1, "12345678", "Ana", "Rojas");
        Empleado empleado = new Empleado(2, "23456789", "Carlos", "Pérez", 2500);
        Consultor consultor = new Consultor(3, "34567890", "Luis", "Torres", "Consultora ABC");

        persona.actividad();
        empleado.actividad();
        consultor.actividad();
        }
        }

Resultado en consola:

La persona realiza una actividad
El empleado trabaja en la empresa
El consultor brinda asesoría

4.3 Combinar super y @Override

@Override
        public void mostrarDatos() {
        super.mostrarDatos();
        System.out.println("Sueldo: " + sueldo);
        }
Idea clave: @Override crea una nueva versión del método; super.mostrarDatos() conserva primero el comportamiento definido en la clase padre.

5. Polimorfismo

El polimorfismo permite que una misma operación presente diferentes comportamientos. Los siguientes ejemplos se realizan en el paquete polimorfismo.

Tipo Mecanismo Se determina
Polimorfismo estático Sobrecarga (overloading) Durante la compilación
Polimorfismo dinámico Sobrescritura (overriding) Durante la ejecución

5.1 Polimorfismo estático: sobrecarga

package polimorfismo;

        public class Persona {
        public void saludar() {
        System.out.println("Hola");
        }

        public void saludar(String nombre) {
        System.out.println("Hola " + nombre);
        }

        public void saludar(String nombre, int edad) {
        System.out.println("Hola " + nombre + ", tienes " + edad + " años");
        }

        public void actividad() {
        System.out.println("La persona realiza una actividad");
        }
        }
Persona persona = new Persona();
        persona.saludar();
        persona.saludar("Carlos");
        persona.saludar("Carlos", 30);

Resultado en consola:

Hola
Hola Carlos
Hola Carlos, tienes 30 años
Sobrecarga: mismo nombre de método y diferentes parámetros. Java selecciona la versión adecuada durante la compilación.

5.2 Polimorfismo dinámico: sobrescritura

package polimorfismo;

        public class Empleado extends Persona {
        @Override
        public void actividad() {
        System.out.println("El empleado trabaja en la empresa");
        }
        }
package polimorfismo;

        public class Consultor extends Persona {
        @Override
        public void actividad() {
        System.out.println("El consultor brinda asesoría");
        }
        }
Persona persona;

        persona = new Empleado();
        persona.actividad();

        persona = new Consultor();
        persona.actividad();

Resultado en consola:

El empleado trabaja en la empresa
El consultor brinda asesoría

5.3 Ejemplo final: arreglo polimórfico

Persona[] personas = {
        new Persona(),
        new Empleado(),
        new Consultor()
        };

        for (Persona persona : personas) {
        persona.actividad();
        }

Resultado en consola:

La persona realiza una actividad
El empleado trabaja en la empresa
El consultor brinda asesoría
Polimorfismo dinámico: una referencia de la clase padre puede apuntar a objetos de clases hijas. La implementación ejecutada depende del objeto real.

6. Práctica: formulario de mascotas

Esta práctica crea un formulario sencillo para seleccionar un animal, registrar su nombre y edad, y mostrar el comportamiento correspondiente. Trabaja en un paquete nuevo para mantener separados los ejemplos anteriores.

6.1 Crear el paquete y las clases

  1. En Source Packages, haz clic derecho y selecciona New → Java Package.
  2. Escribe formulariomascota y pulsa Finish.
  3. Dentro del paquete, crea las clases Animal, Perro, Gato y Ave con New → Java Class.
  4. Escribe el código siguiente en cada archivo antes de crear el formulario.
package formulariomascota;

        public class Animal {
        protected String nombre;
        protected int edad;

        public Animal(String nombre, int edad) {
        this.nombre = nombre;
        this.edad = edad;
        }

        public String getDatos() {
        return "Nombre: " + nombre + "<br>Edad: " + edad;
        }

        public String hacerSonido() {
        return "El animal emite un sonido";
        }
        }
package formulariomascota;

        public class Perro extends Animal {

        public Perro(String nombre, int edad) {
        super(nombre, edad);
        }

        @Override
        public String hacerSonido() {
        return "Guau";
        }
        }
package formulariomascota;

        public class Gato extends Animal {

        public Gato(String nombre, int edad) {
        super(nombre, edad);
        }

        @Override
        public String hacerSonido() {
        return "Miau";
        }
        }
package formulariomascota;

        public class Ave extends Animal {

        public Ave(String nombre, int edad) {
        super(nombre, edad);
        }

        @Override
        public String hacerSonido() {
        return "Pío";
        }
        }

6.2 Crear FormMascota

  1. Haz clic derecho en el paquete formulariomascota y selecciona New → JFrame Form.
  2. En la ventana New File, verifica que esté seleccionada la categoría Swing GUI Forms y el tipo JFrame Form.
  3. Escribe FormMascota como nombre de la clase y pulsa Finish.
  4. NetBeans abrirá la vista Design. A la derecha se encuentra la ventana Palette.
  5. Selecciona el formulario. En Properties, cambia title por Registro de mascotas.

6.3 Agregar y configurar los componentes

Desde Palette → Swing Controls, arrastra los componentes al formulario. Para cambiar el nombre de una variable, haz clic derecho sobre el componente y selecciona Change Variable Name. Para cambiar el texto visible, usa la propiedad text en Properties.

Componente Variable Configuración
Combo Box cbTipo Model → Perro, Gato, Ave
Text Field txtNombre text → vacío
Text Field txtEdad text → vacío
Button btnCrear text → Crear objeto
Button btnMostrar text → Mostrar información
Button btnSalir text → Salir
Label lblResultado text → vacío
Orden recomendado: coloca las etiquetas Tipo, Nombre y Edad a la izquierda de sus controles. Sitúa lblResultado debajo de los botones y amplía su ancho para mostrar varias líneas.

6.4 Declarar la referencia polimórfica

  1. Cambia a la vista Source de FormMascota.java.
  2. Ubica la línea public class FormMascota extends javax.swing.JFrame {.
  3. Justo después de la llave de apertura y antes del constructor public FormMascota(), agrega la referencia.
  4. No declares esta línea dentro de FormMascota(), initComponents() ni un evento de botón.
public class FormMascota extends javax.swing.JFrame {

        private Animal mascota;

        private static final java.util.logging.Logger logger =
        java.util.logging.Logger.getLogger(FormMascota.class.getName());

        public FormMascota() {
        initComponents();
        }
        }

La variable tiene tipo Animal, pero podrá guardar un objeto Perro, Gato o Ave.

6.5 Programar el botón Crear objeto

  1. Vuelve a Design.
  2. Haz doble clic sobre btnCrear. NetBeans abrirá automáticamente btnCrearActionPerformed(...).
  3. Dentro del método generado, escribe el siguiente código:
String tipo = cbTipo.getSelectedItem().toString();
        String nombre = txtNombre.getText().trim();
        String textoEdad = txtEdad.getText().trim();

        if (nombre.isEmpty() || textoEdad.isEmpty()) {
        lblResultado.setText("Completa nombre y edad.");
        return;
        }

        try {
        int edad = Integer.parseInt(textoEdad);

        if (edad < 0) {
        lblResultado.setText("La edad no puede ser negativa.");
        return;
        }

        if (tipo.equals("Perro")) {
        mascota = new Perro(nombre, edad);
        } else if (tipo.equals("Gato")) {
        mascota = new Gato(nombre, edad);
        } else {
        mascota = new Ave(nombre, edad);
        }

        lblResultado.setText("Objeto creado: " + tipo);
        } catch (NumberFormatException e) {
        lblResultado.setText("La edad debe ser un número entero.");
        }

6.6 Programar Mostrar información y Salir

  1. En Design, haz doble clic en btnMostrar y agrega este código.
  2. Haz doble clic en btnSalir y agrega el segundo bloque.
if (mascota == null) {
        lblResultado.setText("Primero crea una mascota.");
        return;
        }

        lblResultado.setText("<html>" + mascota.getDatos()
        + "<br>Sonido: " + mascota.hacerSonido()
        + "</html>");
dispose();

6.7 Ejecutar la práctica

  1. Haz clic derecho en FormMascota.java y selecciona Run File, o presiona Shift + F6.
  2. Selecciona Perro, escribe Max y 3, y pulsa Crear objeto.
  3. Pulsa Mostrar información. Repite la prueba con Gato y Ave.

Resultado esperado para Perro, Max y 3:

Nombre: Max
Edad: 3
Sonido: Guau
Conexión con polimorfismo: mascota mantiene el mismo tipo de referencia, Animal. Sin embargo, hacerSonido() ejecuta la versión de Perro, Gato o Ave según el objeto creado.

7. Resumen

Concepto Java Finalidad
Herencia extends Crear una clase hija a partir de una clase padre.
Constructor padre super(...) Ejecutar el constructor de la clase padre.
Método padre super.metodo() Ejecutar la versión definida en la superclase.
Sobrescritura @Override Proporcionar una nueva implementación heredada.
Polimorfismo estático Sobrecarga Mismo nombre y parámetros diferentes.
Polimorfismo dinámico Sobrescritura La respuesta depende del objeto real.
Secuencia conceptual: Herencia → extends → super → sobrescritura con @Override → sobrecarga → polimorfismo estático → polimorfismo dinámico.
