Antes de programar

Lo que ya sabes de la Sesión 1

Entiende cada concepto con el mismo ejemplo: una mascota con nombre, tipo, edad y peso. Los fragmentos muestran partes de la práctica; en los pasos siguientes los integrarás en sus archivos.

Resultado de aprendizaje

Aplicas conceptos básicos de programación orientada a objetos en la construcción de soluciones informáticas.

Objetivo de hoy

Reconocer, con un ejemplo simple, el patrón que usarás para resolver el laboratorio de forma individual.

01

Clase

Es la definición de un tipo de objeto: indica qué datos puede guardar y qué operaciones ofrece. Mascota define la estructura que compartirán Luna, Max y las demás mascotas.

Mascota.java · estructura
public class Mascota {
              // Aquí van los atributos,
              // el constructor y los métodos.
              }

Piensa: la clase describe cómo será una mascota; declararla todavía no crea a Luna.

02

Objeto

Es una instancia concreta de una clase. Cada objeto Mascota guarda sus propios datos, aunque todos se hayan creado a partir de la misma clase.

Crear dos objetos
Mascota luna = new Mascota(
              "Luna", "Gato", 3, 4.2);
              Mascota max = new Mascota(
              "Max", "Perro", 5, 12.0);

Lee la primera línea: Mascota es el tipo, luna es la variable que guarda una referencia y new Mascota(...) crea e inicializa el objeto.

03

Atributo

Es una variable declarada en la clase que guarda un dato del objeto. En esta práctica, nombre, tipo, edad y peso son atributos de cada mascota.

Dentro de Mascota.java
private String nombre;
              private String tipo;
              private int edad;
              private double peso;

Ejemplo: el atributo edad guarda 3 en Luna y 5 en Max. Estos valores forman parte del estado de cada objeto.

04

Parámetro y argumento

Un parámetro es una variable que recibe un dato al ejecutar un constructor o un método. El argumento es el valor o expresión que envías en la llamada.

Ejemplo del constructor
// En la declaración:
              // int edad es un parámetro.

              // En la llamada, 3 es el
              // argumento para ese parámetro:
              new Mascota("Luna", "Gato", 3, 4.2);

Diferencia clave: el parámetro recibe el dato durante la ejecución; el atributo lo conserva en el objeto. Así los distingue this.

05

Constructor

Inicializa el objeto cuando lo creas con new. Tiene el mismo nombre que la clase y no declara tipo de retorno, ni siquiera void.

Dentro de Mascota.java
public Mascota(String nombre,
              String tipo, int edad,
              double peso) {
              this.nombre = nombre;
              this.tipo = tipo;
              this.edad = edad;
              this.peso = peso;
              }

Lee this.nombre = nombre;: «el atributo nombre de este objeto recibe el valor del parámetro nombre». Si llega "Luna", ese objeto guarda "Luna".

06

Método

Define una operación que se puede ejecutar. Puede consultar datos, modificarlos o realizar otra acción. En Mascota, getEdad() consulta la edad y hacerSonido() devuelve un sonido como texto.

Dentro de Mascota.java
public int getEdad() {
              return edad;
              }

Al llamar luna.getEdad(): el método devuelve 3 como int. No lo muestra en pantalla por sí solo. Otros métodos son void: realizan acciones sin devolver un valor.

07

Encapsulamiento

Reúne los datos y las operaciones en la clase y controla cómo se accede a su estado. Aquí usamos atributos private y métodos public para permitir consultas desde el formulario.

Desde el formulario
// Correcto: consulta pública
              int edad = luna.getEdad();

              // No compila: edad es private
              // luna.edad = 8;

private no significa «no puede cambiar». La propia clase puede modificar sus atributos. Si agregas un método para cambiar la edad, allí puedes comprobar que no sea negativa; private por sí solo no valida datos.

08

Ciclo de vida

Un objeto se crea, se utiliza y, cuando deja de ser alcanzable por el programa, su memoria puede ser liberada por el recolector de basura de Java.

Creación, uso y referencia
// 1. Crear e inicializar
              Mascota luna = new Mascota(
              "Luna", "Gato", 3, 4.2);
              // 2. Usar el objeto
              int edad = luna.getEdad();
              // 3. Quitar esta referencia
              luna = null;

null no destruye el objeto. Si ya no queda ninguna referencia que permita alcanzarlo, podrá ser recolectado; no ocurre necesariamente en ese instante. No necesitas asignar null a cada variable al terminar de usarla.

09

El caso de hoy

El formulario recoge los datos y llama al constructor. El objeto los guarda en sus atributos. Después, el formulario consulta sus métodos y muestra el resultado.

Objeto → método → etiqueta
Mascota luna = new Mascota(
              "Luna", "Gato", 3, 4.2);
              String sonido = luna.hacerSonido();
              lblResultado.setText(sonido);
              // La etiqueta muestra: Miau

Conecta las ideas: tipo es un atributo; hacerSonido() es un método que usa ese dato para decidir qué texto devolver.

Una clase, dos objetos y sus atributos

Ambos objetos son de la clase Mascota, pero cada uno conserva sus propios valores:

Consulta mientras programas

Cómo leer el código de esta guía

Para entender una llamada, identifica quién la recibe, qué método se ejecuta y qué devuelve. Algunos métodos vienen con Java; otros los escribes en tu clase Mascota.

1. Lee lo que está antes y después del punto

Anatomía de una llamada
txtNombre.getText();
            // txtNombre: variable que hace referencia al campo de texto
            // . : permite acceder a un miembro del objeto
            // getText: nombre del método que queremos ejecutar
            // (): llamada sin argumentos; devuelve un String

            miMascota.getEdad();
            // miMascota: variable que hace referencia a un objeto Mascota
            // getEdad(): método que escribimos; devuelve un int

En estas llamadas, el método se ejecuta sobre un objeto. En Integer.parseInt(...), Integer es una clase: parseInt es un método static y se invoca usando el nombre de la clase.

2. ¿En qué se diferencian getText() y getEdad()?

Pregunta txtEdad.getText() miMascota.getEdad()
¿De dónde sale? De la biblioteca Swing de Java. El campo de texto ya dispone de este método. De la clase Mascota. Tú escribiste este método.
¿Qué lee? El texto que contiene el campo del formulario en ese momento. El atributo edad guardado en el objeto.
¿Qué devuelve? Un String, por ejemplo "3". Un int, por ejemplo 3.
¿Para qué lo usamos? Para recoger lo que escribió el usuario. Para consultar la edad de la mascota ya creada.
“get” es una convención de nombres, no una palabra especial de Java. Suele indicar que el método obtiene un valor. El nombre completo, la clase a la que pertenece y su tipo de retorno te dicen qué hace. Escribir un atributo edad no crea automáticamente getEdad().
Dentro de Mascota.java: definición del getter
public int getEdad() {
          return edad;
          }
          // public: permite llamarlo desde el formulario
          // int: tipo del valor que devuelve
          // getEdad: nombre elegido para consultar la edad
          // (): no necesita recibir argumentos
          // return edad: termina el método y entrega el valor del atributo

3. Sigue el recorrido del dato: campo → objeto → etiqueta

Supón que escribes 3 en el campo de edad. Estas líneas ilustran el recorrido dentro del formulario:

FormMascota.java · ejemplo de lectura
// 1. Leer: el campo entrega texto, aunque hayas escrito dígitos
          String textoEdad = txtEdad.getText(); // "3" (String)

          // 2. Convertir: ahora tenemos un número entero
          int edad = Integer.parseInt(textoEdad); // 3 (int)

          // 3. Crear: el constructor guarda la edad en el objeto
          miMascota = new Mascota("Luna", "Gato", edad, 0.0);

          // 4. Consultar: leemos la edad almacenada en la mascota
          int edadGuardada = miMascota.getEdad(); // 3 (int)

          // 5. Mostrar: al unir texto y número con + se forma un String
          lblResultado.setText("Edad: " + edadGuardada);

El campo y el objeto no se sincronizan solos. Si cambias el campo a 5, getText() devolverá "5", pero getEdad() seguirá devolviendo 3. En esta guía, al pulsar otra vez «Crear objeto» se crea una nueva mascota con los datos actuales.

Integer.parseInt() necesita texto que represente un entero dentro del rango de int. Un campo vacío, "tres" o "3.5" provoca NumberFormatException. El ejemplo básico aún no incluye validación; para probarlo, escribe una edad entera como 3.

4. equals(): comparar el contenido de un texto

Lectura de la condición usada en hacerSonido()
String tipo = "Perro";
          boolean esPerro = tipo.equals("Perro"); // true
          boolean mismoTexto = tipo.equals("perro"); // false: cambia la mayúscula

          if (tipo.equals("Perro")) {
          // Este bloque se ejecuta cuando la comparación devuelve true
          }

equals() es un método que usamos sobre un String para comparar su contenido con el argumento entre paréntesis. Devuelve un boolean: true o false. Distingue mayúsculas y espacios: "Perro", "perro" y "Perro " son textos diferentes.

Para comparar el contenido de dos cadenas usa equals(). Entre referencias a objetos, == comprueba si apuntan al mismo objeto; por eso no lo usamos para comparar estos textos. En miMascota == null sí corresponde: comprobamos si la variable no tiene un objeto asignado.

En esta práctica, el combo contiene Perro, Gato y Ave. El else de hacerSonido() cubre cualquier valor que no coincida con los dos primeros; no comprueba expresamente que sea Ave.

8. this.: «este objeto»

this es una referencia al objeto actual. Dentro del constructor de Mascota, se refiere a la mascota que se está inicializando. Dentro de un método de instancia, se refiere a la mascota sobre la que llamaste al método. El punto permite acceder a un miembro: this.edad se lee «el atributo edad de este objeto».

Mascota.java · el constructor de la práctica
public Mascota(String nombre, String tipo, int edad, double peso) {
          this.nombre = nombre;
          this.tipo = tipo;
          this.edad = edad;
          this.peso = peso;
          }
          // this.edad: atributo que pertenece al objeto
          // edad: parámetro que recibe el constructor
          // =: toma el valor de la derecha y lo guarda a la izquierda
En this.edad = edad; ¿A qué se refiere? Si recibimos 3
this.edad Al atributo declarado con private int edad;. Es parte del estado del objeto. Es el destino donde se guardará 3.
edad Al parámetro int edad. Está disponible durante la ejecución del constructor. Contiene el valor 3 recibido al crear la mascota.
= A la asignación: copia el valor de la derecha en la variable de la izquierda. El atributo del objeto queda con el valor 3.

El atributo y el parámetro son dos variables distintas que aquí tienen el mismo nombre. Dentro del constructor, el parámetro tiene prioridad cuando escribes solamente edad. Por eso usamos this.edad para indicar que queremos modificar el atributo.

¿Qué pasa si escribo edad = edad;? En este constructor, asignas el parámetro a sí mismo. La línea compila, pero no guarda el dato en el atributo. Como private int edad; no tiene un valor inicial explícito, el atributo de la nueva mascota conservaría su valor predeterminado: 0.
Dos mascotas: cada objeto tiene su propia edad
Mascota luna = new Mascota("Luna", "Gato", 3, 4.2);
          // En esta ejecución del constructor, this se refiere al objeto de Luna

          Mascota max = new Mascota("Max", "Perro", 5, 12.0);
          // En esta otra ejecución, this se refiere al objeto de Max

          int edadLuna = luna.getEdad(); // 3
          int edadMax = max.getEdad(); // 5

¿Siempre debo escribir this.? Puedes omitirlo cuando no haya un parámetro o una variable local con el mismo nombre que oculte al atributo. En tu getter, return edad; y return this.edad; consultan el mismo atributo, porque getEdad() no tiene un parámetro llamado edad.

También podrías llamar edadInicial al parámetro y escribir this.edad = edadInicial; o edad = edadInicial;. Usar el mismo nombre con this. es una forma habitual de mantener clara la relación entre ambos.

this también puede usarse para llamar a un método del objeto, como this.getEdad() dentro de Mascota. No se puede usar directamente dentro de un método static, como main: allí debes crear u obtener un objeto y usar su variable, por ejemplo luna.getEdad().

9. void: ejecutar sin devolver un valor

void indica que un método no entrega un valor de retorno a quien lo llama. Puede realizar acciones, como cambiar una etiqueta, crear un objeto o cerrar la aplicación. No significa que el método esté vacío, que no haga nada o que no pueda recibir parámetros.

Declaración o llamada ¿Qué devuelve? ¿Cómo se usa?
public int getEdad() Un número entero mediante return edad;. int edad = miMascota.getEdad();
public String hacerSonido() Un texto, por ejemplo "Miau". String sonido = miMascota.hacerSonido();
lblResultado.setText("Hola") Ningún valor: su retorno es void. Cambia la etiqueta. Se ejecuta como una instrucción: lblResultado.setText("Hola");
private void btnMostrarActionPerformed(java.awt.event.ActionEvent evt) Ningún valor. Atiende el evento y actualiza la interfaz. Se ejecuta al pulsar el botón y recibe el evento en evt.
FormMascota.java · void y una salida anticipada
private void btnMostrarActionPerformed(java.awt.event.ActionEvent evt) {
          if (miMascota == null) {
          lblResultado.setText("Primero crea el objeto.");
          return; // termina este evento sin devolver un valor
          }

          lblResultado.setText("Edad: " + miMascota.getEdad());
          // Al llegar al final, el método termina. No necesita otro return.
          }

Mostrar un texto y devolver un valor son cosas distintas. getEdad() devuelve un número al código que lo llamó; por sí solo no lo muestra en pantalla. setText(...) modifica el texto de la etiqueta y su retorno es void.

Qué puedes guardar en una variable
// Correcto: getEdad devuelve un int que podemos guardar
          int edad = miMascota.getEdad();

          // Correcto: setText realiza una acción y se llama sin asignar su resultado
          lblResultado.setText("Edad: " + edad);

          // Incorrecto: setText es void; esta línea no compilaría
          // String resultado = lblResultado.setText("Hola");

Un método void puede usar return; para salir antes, pero no return edad; ni return null;. Un método declarado con retorno int debe entregar un valor compatible cuando termina normalmente. Los parámetros se leen entre paréntesis: getEdad() no recibe ninguno; el evento sí recibe evt, aunque sea void.

El constructor no lleva void. public Mascota(...) es el constructor porque tiene el nombre de la clase y no declara tipo de retorno. Si escribieras public void Mascota(...), declararías un método común llamado Mascota; no sería el constructor que se invoca con new.
Si reemplazas this.edad = edad; por edad = edad; en el constructor y creas una mascota con edad 3, ¿qué devolverá getEdad()?＋
Devolverá 0 en esta clase: el parámetro se asignó a sí mismo y el atributo quedó con su valor inicial predeterminado. this.edad = edad; guarda el 3 recibido en el atributo del objeto.
¿Un método void puede recibir datos y cambiar lo que ves en pantalla?＋
Sí. lblResultado.setText("Hola") recibe un texto y cambia la etiqueta. void solo indica que no entrega un valor de retorno para guardarlo o usarlo en otra expresión.
Creaste una mascota con edad 3 y luego escribiste 5 en el campo sin pulsar «Crear objeto». ¿Qué devuelve cada método?＋
txtEdad.getText() devuelve "5" como String. miMascota.getEdad() devuelve 3 como int, porque el objeto conserva la edad recibida en el constructor.
