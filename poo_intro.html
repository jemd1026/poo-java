06
SELECCIÓN DE OPCIONES

Elige un camino con switch.

La estructura switch permite comparar una expresión con varios valores posibles. Es muy útil para seleccionar un día de la semana.

Elegiste: Lunes

DiasSemana.java
int dia = 3;
              String nombreDia;

              switch (dia) {
              case 1: nombreDia = "Lunes"; break;
              case 2: nombreDia = "Martes"; break;
              case 3: nombreDia = "Miércoles"; break;
              default: nombreDia = "Día inválido";
              }

EJERCICIO APLICADO · PERÚ

Ejemplo 1: sueldos por categoría.

Una pequeña bodega peruana necesita calcular el sueldo de sus empleados según el puesto elegido. Trabajaremos con soles y tres categorías.

EL PROBLEMA

Calcula y muestra el sueldo correspondiente.

01ReponedorS/ 1,589 + bono del 10%
02CajeroS/ 2,563.09 fijo
03SupervisorS/ 3,556.20 - 11%
SueldosPeru.java · SOLUCIÓN
import java.util.Scanner;

              Scanner teclado = new Scanner(System.in);
              System.out.print("Categoría (1, 2 o 3): ");
              int categoria = teclado.nextInt();
              double sueldo;

              switch (categoria) {
              case 1: sueldo = 1589 * 1.10; break;
              case 2: sueldo = 2563.09; break;
              case 3: sueldo = 3556.20 * 0.89; break;
              default: sueldo = 0;
              }
              System.out.printf("Sueldo: S/ %.2f%n", sueldo);

EJEMPLO 4 · VECTORES

Cuenta cuántas veces aparece el 2.

Ingresa 10 números en un vector. Al finalizar, el programa recorre los valores e informa cuántas veces se ingresó el número 2.

EL DESAFÍO

Cargar 10 números y contar las coincidencias.

Usa un vector, un ciclo para cargar los datos y otro ciclo para revisar si cada valor es igual a 2.

ContarDoses.java · SOLUCIÓN
import java.util.Scanner;

              int[] vector = new int[10];
              Scanner teclado = new Scanner(System.in);

              for (int i = 0; i < vector.length; i++) {
              System.out.print("Número " + (i + 1) + ": ");
              vector[i] = teclado.nextInt();
              }

              int cantidadDos = 0;
              for (int i = 0; i < vector.length; i++) {
              if (vector[i] == 2) cantidadDos++;
              }
              System.out.println("El número 2 aparece: " + cantidadDos + " veces");

DECISIÓN EN UNA LÍNEA

Operador ternario.

El operador ternario permite elegir entre dos resultados en una sola expresión: uno para cuando la condición es verdadera y otro para cuando es falsa.

variable = (condición) ? valor_si_verdadero : valor_si_falso;
Promedio.java · EJEMPLO
double promedio = 7.5;
              String condicionFinal;

              condicionFinal = promedio >= 6
              ? "Aprobado"
              : "Desaprobado";

              System.out.println("Condición final: " + condicionFinal);

Resultado: Aprobado

MISIÓN DESBLOQUEADA

Desafío final: promedio de notas.

Usa un vector de cinco notas, un ciclo para sumarlas y el operador ternario para decidir si el estudiante aprobó.

EL DESAFÍO

¿El promedio es igual o mayor que 6?

Ingresa cinco notas entre 0 y 10. Calcula el promedio y muestra Aprobado o Desaprobado.

PromedioNotas.java · SOLUCIÓN
double[] notas = {7, 8, 5, 6, 9};
                double suma = 0;

                for (int i = 0; i < notas.length; i++) {
                suma += notas[i];
                }

                double promedio = suma / notas.length;
                String resultado = promedio >= 6
                ? "Aprobado" : "Desaprobado";
