abstract class Participante {
  abstract void resolver();
}

  int obtenerPuntos();
}

  extends Participante
  implements Evaluable {
  public void resolver() {
    System.out.println("¡Reto superado!");
  }
  public int obtenerPuntos() {
    return 20;
  }
}

01 / Participantes

Ocho equipos. Un mismo desafío.

Los equipos ya están numerados. Cada uno se organiza internamente y rota las responsabilidades en cada reto para que los cinco integrantes participen.

Roles rotativos: coordinador, analista, programador A, programador B y evaluador/probador. Todos deben poder explicar y modificar el código. El docente puede elegir al azar quién defenderá la solución.

03 / Laboratorio de retos

Ejercicios oficiales

Cuatro retos de dificultad progresiva, centrados exclusivamente en POO. En cada duelo, los dos equipos resuelven el mismo reto para asegurar una comparación justa. Los casos se pueden desarrollar por consola o con formularios Swing si ya los han practicado.

Condiciones de entrega: proyecto Java ejecutable, código fuente organizado por clases, captura del resultado y breve explicación de dónde se aplicó cada concepto. No se exige base de datos, archivos, colecciones avanzadas ni frameworks.

05 / Evaluación cruzada

¿Cómo se ganan los puntos?

Se usa la misma rúbrica para todos los retos. La evaluación del equipo contrario es orientativa y el docente valida la nota final.

05 pts

Funcionamiento

El código compila, ejecuta y responde a los casos solicitados.

05 pts

Aplicación POO

Uso correcto de herencia, polimorfismo, abstracción e interfaces según el reto.

03 pts

Calidad del código

Nombres claros, encapsulamiento y responsabilidades bien separadas.

04 pts

Defensa individual

Los integrantes explican decisiones y realizan pequeños cambios.

03 pts

Pruebas y mejora

Detectan errores, prueban escenarios y justifican correcciones.

Reglas de convivencia: no se permiten burlas ni sabotajes. El rival formula dos preguntas técnicas respetuosas y reporta un acierto y una mejora. La calificación académica la define el docente (sugerencia: docente 60 %, coevaluación 20 %, desempeño individual 20 %).
