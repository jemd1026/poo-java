Mantenimiento de Productos con MVC

Un segundo ejercicio completo, del mismo tipo que el Registro de Personas: un formulario Swing para registrar, modificar, eliminar y buscar los productos de un sistema POS, organizado en Modelo, Vista y Controlador.

Antes de empezar: esta práctica usa los mismos pasos que la sección 6 de la guía MVC (paquetes, JFrame Form, Button Group, eventos en el Controlador). Si alguno no te queda claro, repásalo allí.
← Volver a la guía MVC · Registro de Personas

1. Enunciado del ejercicio

Una tienda necesita una ventana para el mantenimiento de productos de su sistema de punto de venta (POS). El formulario debe permitir:

  • Registrar productos con nombre, modelo, tipo de producto, categoría, marca, tipo (Bien o Servicio), estado, fecha de vencimiento opcional, stock, precio de compra y precio de venta.
  • Elegir Tipo Producto, Categoría y Marca desde listas desplegables con 5 opciones cada una.
  • Mostrar todos los productos en una tabla y, al hacer clic en una fila, cargar sus datos en el formulario.
  • Modificar y eliminar el producto seleccionado, buscar por texto y cancelar la operación.
  • Generar el código del producto y la fecha de registro de forma automática.

Opciones de las listas desplegables

Tipo Producto

  1. Perecible
  2. No perecible
  3. Duradero
  4. Consumible
  5. Intangible

Categoría

  1. Útiles de oficina
  2. Computación
  3. Alimentos y bebidas
  4. Limpieza
  5. Servicios

Marca

  1. Faber-Castell
  2. Logitech
  3. Gloria
  4. Bolívar
  5. Genérica

Cada lista empieza con la opción -- Seleccione --, que no cuenta como una respuesta válida.

Reglas del negocio

3. Modelo

3.1 Clase Producto

En productos.modelo, crea la clase Producto. Guarda los datos de un producto y contiene sus reglas propias: calcular la utilidad, saber si es un servicio y saber si tiene fecha de vencimiento.

Archivo · Producto.java (dentro del paquete productos.modelo)

package productos.modelo;

import java.time.LocalDate;

public class Producto {
    private int codigo;
    private final String nombre;
    private final String modelo;
    private final String tipoProducto;
    private final String categoria;
    private final String marca;
    private final String tipo;
    private final boolean activo;
    private final LocalDate fechaVencimiento;
    private final int stock;
    private final double precioCompra;
    private final double precioVenta;
    private LocalDate fechaRegistro;

    public Producto(String nombre, String modelo, String tipoProducto, String categoria,
                    String marca, String tipo, boolean activo, LocalDate fechaVencimiento,
                    int stock, double precioCompra, double precioVenta) {
        this.nombre = nombre;
        this.modelo = modelo;
        this.tipoProducto = tipoProducto;
        this.categoria = categoria;
        this.marca = marca;
        this.tipo = tipo;
        this.activo = activo;
        this.fechaVencimiento = fechaVencimiento;
        this.stock = stock;
        this.precioCompra = precioCompra;
        this.precioVenta = precioVenta;
    }

    void asignarCodigo(int codigo, LocalDate fechaRegistro) {
        this.codigo = codigo;
        this.fechaRegistro = fechaRegistro;
    }

    public double calcularUtilidad() {
        return precioVenta - precioCompra;
    }

    public boolean esServicio() {
        return tipo.equals("Servicio");
    }

    public boolean tieneVencimiento() {
        return fechaVencimiento != null;
    }

    public int getCodigo() {
        return codigo;
    }

    public String getNombre() {
        return nombre;
    }

    public String getModelo() {
        return modelo;
    }

    public String getTipoProducto() {
        return tipoProducto;
    }

    public String getCategoria() {
        return categoria;
    }

    public String getMarca() {
        return marca;
    }

    public String getTipo() {
        return tipo;
    }

    public boolean isActivo() {
        return activo;
    }

    public LocalDate getFechaVencimiento() {
        return fechaVencimiento;
    }

    public int getStock() {
        return stock;
    }

    public double getPrecioCompra() {
        return precioCompra;
    }

    public double getPrecioVenta() {
        return precioVenta;
    }

    public LocalDate getFechaRegistro() {
        return fechaRegistro;
    }
}

Casi todos los atributos son final: un producto no cambia después de crearlo. Las excepciones son codigo y fechaRegistro, que no los escribe el usuario. Los asigna RegistroProductos al guardar el producto.

Encapsulamiento: asignarCodigo(...) no tiene modificador de acceso; por eso solo lo pueden usar las clases del mismo paquete (productos.modelo). El Controlador y la Vista no pueden cambiar el código de un producto.
Dos «modelos»: el atributo modelo de Producto es el modelo comercial del artículo (por ejemplo, M170). No tiene relación con el Modelo de MVC.

3.2 Clase RegistroProductos

En el mismo paquete, crea RegistroProductos. Guarda la lista en memoria, genera los códigos, evita los duplicados y permite buscar.

Archivo · RegistroProductos.java (dentro del paquete productos.modelo)

package productos.modelo;

import java.time.LocalDate;
import java.util.ArrayList;
import java.util.List;

public class RegistroProductos {
    private final List<Producto> productos = new ArrayList<>();
    private int ultimoCodigo = 0;

    public boolean registrar(Producto producto) {
        if (existeDuplicado(producto, 0)) {
            return false;
        }
        ultimoCodigo++;
        producto.asignarCodigo(ultimoCodigo, LocalDate.now());
        productos.add(producto);
        return true;
    }

    public boolean modificar(int codigo, Producto producto) {
        int indice = buscarIndice(codigo);
        if (indice == -1 || existeDuplicado(producto, codigo)) {
            return false;
        }
        LocalDate fechaRegistro = productos.get(indice).getFechaRegistro();
        producto.asignarCodigo(codigo, fechaRegistro);
        productos.set(indice, producto);
        return true;
    }

    public void eliminar(int codigo) {
        int indice = buscarIndice(codigo);
        if (indice != -1) {
            productos.remove(indice);
        }
    }

    public Producto buscarPorCodigo(int codigo) {
        int indice = buscarIndice(codigo);
        return indice == -1 ? null : productos.get(indice);
    }

    public List<Producto> listar() {
        return productos;
    }

    public List<Producto> buscar(String texto) {
        String filtro = texto.toLowerCase();
        List<Producto> encontrados = new ArrayList<>();
        for (Producto p : productos) {
            if (p.getNombre().toLowerCase().contains(filtro)
                    || p.getModelo().toLowerCase().contains(filtro)
                    || p.getCategoria().toLowerCase().contains(filtro)
                    || p.getMarca().toLowerCase().contains(filtro)) {
                encontrados.add(p);
            }
        }
        return encontrados;
    }

    private boolean existeDuplicado(Producto nuevo, int codigoActual) {
        for (Producto p : productos) {
            if (p.getCodigo() != codigoActual
                    && p.getNombre().equalsIgnoreCase(nuevo.getNombre())
                    && p.getModelo().equalsIgnoreCase(nuevo.getModelo())
                    && p.getMarca().equals(nuevo.getMarca())) {
                return true;
            }
        }
        return false;
    }

    private int buscarIndice(int codigo) {
        for (int i = 0; i < productos.size(); i++) {
            if (productos.get(i).getCodigo() == codigo) {
                return i;
            }
        }
        return -1;
    }
}

Los productos se buscan por código y no por la posición en la lista. Cuando la tabla muestra un resultado de búsqueda, la fila 0 puede ser el producto 5, así que la posición dejaría de servir.

En existeDuplicado, el parámetro codigoActual excluye al propio producto: al registrar se pasa 0 (ningún producto tiene ese código) y al modificar se pasa el código del producto que se está editando, para que no se compare consigo mismo.

4.3 Programar los métodos de la Vista

Cambia a Source. Agrega los import, la constante FORMATO, el atributo modeloTabla, completa el constructor después de initComponents(); y escribe los demás métodos antes de la zona gris generada por NetBeans.

package productos.vista;

import java.awt.event.ActionListener;
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.time.format.ResolverStyle;
import java.util.List;
import java.util.Locale;
import javax.swing.JOptionPane;
import javax.swing.ListSelectionModel;
import javax.swing.event.ListSelectionListener;
import javax.swing.table.DefaultTableModel;

public class FrmProducto extends javax.swing.JFrame {

                return false;

        chkVencimiento.addItemListener(e -> txtVencimiento.setEnabled(chkVencimiento.isSelected()));

        setLocationRelativeTo(null);
    }

        return String.format(Locale.US, "%.2f", valor);

5. Controlador: clase ProductoController

En productos.controlador, crea ProductoController. Escucha los seis botones (y la tecla Enter en txtBuscar) con ActionListener, y la tabla con ListSelectionListener.

Archivo · ProductoController.java (dentro del paquete productos.controlador)

package productos.controlador;

import java.awt.event.ActionEvent;
import java.awt.event.ActionListener;
import java.time.LocalDate;
import java.time.format.DateTimeParseException;
import java.util.Locale;
import javax.swing.event.ListSelectionEvent;
import javax.swing.event.ListSelectionListener;
import productos.modelo.Producto;
import productos.modelo.RegistroProductos;
import productos.vista.FrmProducto;

public class ProductoController implements ActionListener, ListSelectionListener {
    private final RegistroProductos modelo;
    private final FrmProducto vista;

    public ProductoController(RegistroProductos modelo, FrmProducto vista) {
        this.modelo = modelo;
        this.vista = vista;
        vista.agregarEventos(this, this);
        vista.listar(modelo.listar());
    }

    @Override
    public void actionPerformed(ActionEvent e) {
        switch (e.getActionCommand()) {
            case "Nuevo":
                vista.limpiar();
                break;
            case "Registrar":
                registrar();
                break;
            case "Modificar":
                modificar();
                break;
            case "Eliminar":
                eliminar();
                break;
            case "Cancelar":
                cancelar();
                break;
            case "Buscar":
                actualizarTabla();
                break;
        }
    }

    @Override
    public void valueChanged(ListSelectionEvent e) {
        int codigo = vista.getCodigoSeleccionado();
        if (e.getValueIsAdjusting() || codigo == -1) {
            return;
        }
        vista.mostrarProducto(modelo.buscarPorCodigo(codigo));
    }

    private void registrar() {
        if (vista.getCodigoSeleccionado() != -1) {
            vista.mostrarMensaje("Hay un producto seleccionado. Pulsa Nuevo para registrar otro.");
            return;
        }
        Producto producto = leerProducto();
        if (producto == null) {
            return;
        }
        if (modelo.registrar(producto)) {
            actualizarTabla();
            vista.limpiar();
            vista.mostrarMensaje("Producto registrado con código " + producto.getCodigo()
                    + ".\nUtilidad por unidad: S/ "
                    + String.format(Locale.US, "%.2f", producto.calcularUtilidad()));
        } else {
            vista.mostrarMensaje("Ya existe un producto con ese nombre, modelo y marca.");
        }
    }

    private void modificar() {
        int codigo = vista.getCodigoSeleccionado();
        if (codigo == -1) {
            vista.mostrarMensaje("Selecciona un producto en la tabla.");
            return;
        }
        Producto producto = leerProducto();
        if (producto == null) {
            return;
        }
        if (modelo.modificar(codigo, producto)) {
            actualizarTabla();
            vista.limpiar();
            vista.mostrarMensaje("Producto modificado.");
        } else {
            vista.mostrarMensaje("Ya existe otro producto con ese nombre, modelo y marca.");
        }
    }

    private void eliminar() {
        int codigo = vista.getCodigoSeleccionado();
        if (codigo == -1) {
            vista.mostrarMensaje("Selecciona un producto en la tabla.");
            return;
        }
        Producto producto = modelo.buscarPorCodigo(codigo);
        if (vista.confirmar("¿Eliminar el producto " + producto.getNombre() + "?")) {
            modelo.eliminar(codigo);
            actualizarTabla();
            vista.limpiar();
        }
    }

    private void cancelar() {
        vista.limpiarBusqueda();
        actualizarTabla();
        vista.limpiar();
    }

    private void actualizarTabla() {
        vista.listar(modelo.buscar(vista.getTextoBuscar()));
    }

    private Producto leerProducto() {
        String error = validar();
        if (error != null) {
            vista.mostrarMensaje(error);
            return null;
        }
        LocalDate vencimiento = vista.tieneVencimiento() ? vista.getFechaVencimiento() : null;
        return new Producto(vista.getNombre(), vista.getModelo(), vista.getTipoProducto(),
                vista.getCategoria(), vista.getMarca(), vista.getTipo(), vista.isActivo(),
                vencimiento, Integer.parseInt(vista.getStock()),
                Double.parseDouble(vista.getPrecioCompra()),
                Double.parseDouble(vista.getPrecioVenta()));
    }

    private String validar() {
        if (vista.getNombre().isEmpty() || vista.getTipoProducto().isEmpty()
                || vista.getCategoria().isEmpty() || vista.getMarca().isEmpty()) {
            return "Completa nombre, tipo de producto, categoría y marca.";
        }
        if (!vista.getNombre().matches("[\\p{L}\\d .-]+")) {
            return "El nombre solo puede contener letras, números, espacios, puntos y guiones.";
        }
        if (!vista.getStock().matches("\\d+")) {
            return "El stock debe ser un número entero, por ejemplo 25.";
        }
        if (!vista.getPrecioCompra().matches("\\d+(\\.\\d{1,2})?")
                || !vista.getPrecioVenta().matches("\\d+(\\.\\d{1,2})?")) {
            return "Escribe los precios con hasta 2 decimales, por ejemplo 12.50.";
        }

        double compra = Double.parseDouble(vista.getPrecioCompra());
        double venta = Double.parseDouble(vista.getPrecioVenta());
        if (compra <= 0) {
            return "El precio de compra debe ser mayor que 0.";
        }
        if (venta < compra) {
            return "El precio de venta no puede ser menor que el precio de compra.";
        }

        if (vista.getTipo().equals("Servicio")) {
            if (!vista.getStock().matches("0+")) {
                return "Un servicio no maneja stock: deja el stock en 0.";
            }
            if (vista.tieneVencimiento()) {
                return "Un servicio no tiene fecha de vencimiento.";
            }
        }
        if (vista.getTipoProducto().equals("Perecible") && !vista.tieneVencimiento()) {
            return "Un producto perecible debe tener fecha de vencimiento.";
        }
        if (vista.tieneVencimiento()) {
            LocalDate fecha;
            try {
                fecha = vista.getFechaVencimiento();
            } catch (DateTimeParseException ex) {
                return "Escribe la fecha de vencimiento con el formato dd/MM/aaaa.";
            }
            if (!fecha.isAfter(LocalDate.now())) {
                return "La fecha de vencimiento debe ser posterior a hoy.";
            }
        }
        return null;
    }
}

El switch elige la acción según el texto del botón (o su actionCommand). Buscar y Cancelar usan el mismo método actualizarTabla(): si el campo de búsqueda está vacío, modelo.buscar("") devuelve todos los productos, porque cualquier texto contiene la cadena vacía.

Las validaciones con matches(...) usan estas expresiones regulares:

ExpresiónSignificadoVálidoNo válido
[\\p{L}\\d .-]+Letras, dígitos, espacios, puntos y guionesCuaderno A4Abc$
\\d+Uno o más dígitos (entero sin signo)25-5, 2.5
\\d+(\\.\\d{1,2})?Entero con hasta 2 decimales opcionales, separados por punto12, 12.5, 12.5012,50, 12.505
0+Solo ceros03
Orden de las validaciones: los precios se convierten con Double.parseDouble solo después de comprobar su formato con matches; por eso no hace falta capturar NumberFormatException. La fecha sí se lee dentro de try / catch, porque una fecha como 31/02/2027 tiene el formato correcto pero no existe.
